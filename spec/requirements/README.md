# 需求分析轮次

一轮完整的需求分析对应一个独立目录；同一轮内的问答持续更新本轮资料，不为每次问答另开目录。

| 轮次 | 主题 | 状态 | 入口 |

当前轮次见 [CURRENT.md](CURRENT.md)。后续新一轮按 `002-主题`、`003-主题` 递增编号，拥有各自的需求记录和来源目录；不覆盖前一轮正文。第 001 轮已按用户要求整理终版需求；本次未新开轮次，也未进入架构设计或实现。

每轮目录包含：

- `README.md`：本轮范围、状态和资料入口。
- `REQUIREMENTS.md`：本轮唯一需求正文；收束后整理为终版，区分已确认范围、验收与未固定事项。
- `sources/`：本轮来源记录；已被引用的来源原文保持不变，新的确认或纠正另增文件。

全局唯一讨论状态仍位于 [WORKING.json](../architecture/WORKING.json)，用于当前讨论的连续性和证据引用，不在各轮复制另一份可写状态。
