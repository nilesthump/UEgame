# 第 001 轮：因果体验快速原型

开始日期：2026-10-30（Asia/Shanghai）。终版整理日期：2026-10-31；活动边界修订：2026-11-05。状态：终版需求已整理，当前进行架构逐项确认，尚未实现。

本轮验证“救助方式 → 教师科目 → 小镇学习风气”能否让玩家感到自己的选择改变了世界。用户本人比较剑术、魔法、混用、未获救四类结果；成功路线目标约 10 分钟（5 + 2 + 3）。

玩家在小镇周边森林救助遭 5 只持棒哥布林威胁的小孩；成功后直接跨越 30 年，在镇子回访。知名教师有公开课与群众讨论，学习风气以群众闲聊体现。教师本人相见时提起救援，玩家离开时会挽留。本轮不细化课程、不实验练习达标或能力成长。

保留已确认的球体世界与可旋转缩放的小地图、挥砍／火球／岩炮弹、移动闪避与防反，以及森林火灾、降雨、砍树与倒木阻挡；回访有枯木新芽与树桩。玩家活动限于小镇及周边森林，采用空气墙限制范围，非活动区不建模。全部行为边界以[需求记录](REQUIREMENTS.md)为准。

平台为 UE5／Windows PC，支持键鼠和模拟手柄信号、第一／第三人称切换；无真实手柄设备测试条件。采用灰盒与简单表现，数值和表现细节留待试玩调整。每轮保留救助方式、分支、成败原因和阶段耗时，成败均手动重启原实验世界。
