# 终版需求：第 001 轮因果体验快速原型

整理日期：2026-10-31（Asia/Shanghai）；活动边界及输入/闪避修订：2026-11-05；球面弹道澄清：2026-11-06。本文为本轮唯一有效需求正文，汇总当前已确认需求，并以最新明确回答覆盖较早冲突表述。原始回答保留在 [sources](sources/README.md)，讨论证据保留在 [WORKING.json](../../architecture/WORKING.json)。

“终版”指本轮需求整理完成；不表示原型已实现、实验已通过或架构已冻结。A01–A13已完成逐项确认；后续[仓库初始化与性能指示](sources/2026-11-06-repository-bootstrap-and-latency.md)授权规范目录、模块分工和本地仓库初始化，尚未开始游戏实现。

## 1. 实验目标与范围

**验证玩家能否理解自己的救助方式带来的后果，并感到自己的选择改变了世界。**

核心体验为：在小镇周边森林救助小孩，以剑术、魔法或两者混用影响其未来方向；成功后直接跨越 30 年，回到镇子，通过群众闲聊、教师本人叙述和森林变化感知早期行为的后果。

允许少量预先设计的事件与结果。首轮验证因果感受，不要求证明通用社会演化能力。唯一真人试玩者为用户本人；本轮为单玩家体验。

| 范围 | 本轮要求 |
| --- | --- |
| 必需内容 | 森林救援、三类救助方式与未获救结果、30 年后回访、球体世界与球体小地图、战斗引起的森林变化、结果日志与手动复测 |
| 场景 | 一座小镇及周边森林；玩家活动限于小镇及周边 |
| 建模与简化 | 活动区以空气墙限制；非活动区不建模；使用灰盒和简单表现；因果结果可预先设计 |
| 本轮不实验 | 玩家听课学习、练习达标、熟练度考核、玩家或居民的能力成长 |
| 后续意向 | 多人共同影响、完整社会演化、经济法律、住房生活、更多主线与学习成长系统 |

## 2. 平台、输入与原型品质

- 使用 UE5，只面向 Windows PC。
- 支持键盘鼠标和手柄输入；支持第一人称与第三人称切换。
- 地图操作模式不接收新的移动、跳跃、闪避和攻击；已有动作、重力和世界继续运行，不因操作地图暂停世界或刷新无敌。失焦、解绑及模式切换清除未消费输入；初始按键映射可调。依据：[A05 总体确认](sources/2026-11-05-a05-confirmation.md)。
- 实验设备没有手柄，手柄只能模拟信号输入，无法进行真实设备测试。验证记录须明确模拟测试与实物测试的区别，不能将模拟通过记为实物兼容性或手感通过。
- 按已核验的 Epic 官方原型指导，先用灰盒与简单表现验证玩法，尽早试玩、根据反馈迭代，成品美术后置。具体依据见[官方方法记录](sources/2026-10-30-epic-prototyping-evidence.md)；教程中的模板、资产和技术做法不因此成为本项目要求。

## 3. 实验流程与时间

### 3.1 成功路线

| 阶段 | 目标实际时长 | 玩家体验 |
| --- | --- | --- |
| 救援 | 约 5 分钟 | 森林采药途中偶然发现遇险现场，观察并选择安全的救法 |
| 加速发展 | 约 2 分钟 | 直接跨越游戏世界的 30 年，玩家看不见中间变化 |
| 回访 | 约 3 分钟 | 在镇上恢复行动，感知学习风气、听到教师提起救援，并回访森林后果 |

合计目标约 10 分钟。以上是体验时长目标，不引入超时失败或强制结束规则。

“不干预”指玩家看不见发展中的变化；现场旁观不属于本轮的不干预阶段。无需安排在别处自由活动的等待过程，也不要求展示中间演化。剧情跳时与正常衰老区分，沿用已确认的剧情跳时不消耗玩家年龄及剩余寿命的规则。

### 3.2 三个不同起点

| 用途 | 起点 |
| --- | --- |
| 遇险事件发展、预设降雨计时 | 本轮世界开始运行时 |
| 救助方式统计 | 玩家接近并发现小孩正受到魔物威胁时；此前使用不计入 |
| 日志中的救援阶段耗时 | 玩家首次朝哥布林挥砍或施法时；未命中也开始计时 |

若玩家始终没有攻击，小孩就遇难，救援耗时记为“未开始”。三个起点不合并计算。

## 4. 森林救援与因果分支

### 4.1 现场与敌人

- 森林采药只交代背景，不要求寻找或采下药草。玩家在路上偶然看见遇险现场；正常沿路到达后，留有观察与选择安全救法的时间。
- 遇险事件从本轮世界开始运行时持续发展，不等待玩家发现。玩家迟到时，小孩可能已经遇难。
- 威胁小孩的魔物仅为 5 只持棒哥布林；小孩原地抱头瘫坐哭泣。
- 五只哥布林可以围攻玩家，攻击小孩时采用同样节奏，不要求轮流出手，也不要求五只精确同步攻击。
- 玩家朝任一哥布林挥砍或施法，即使没有命中，也触发全体哥布林转向玩家；不要求攻击从其附近掠过。该规则只判定攻击目标变化，不让未命中的攻击造成伤害。
- 玩家离事件中心超过一定距离后脱战，哥布林返回攻击小孩。
- 哥布林被防反击飞、摔落后若存活，会试图捡回棒子继续攻击；捡棒受阻时尝试徒手攻击。

按 [A07 总体确认](sources/2026-11-06-a07-confirmation.md)补齐：

- 脱战按玩家与固定事件中心的参考球面短弧距离，跳跃高度不影响；外圈攻击仍登记指向与计时，但越界检查优先于持续追击。走回范围内不自动拉仇恨，再攻击才转向；脱战不回血、不补棒。
- 五只按独立节奏横竖交替；攻击各阶段停止自主平移，前摇有限转向，有效挥动锁定方向。切目标取消旧前摇，已生效挥动和收招继续；重复同目标攻击不重置节奏，死亡/防反仍按第 5 节处理。
- 落地伤害已经结算且仍存活，才尝试捡自己的原棒；真实无路或持续无进展转徒手，之后在阻挡变化或间隔到期且当前攻击结束时重试。发出拾取请求不等于已拾取，反复拒绝不能无限重置等待。
- 徒手为短程直拳，真实接触造成可承受多次的普通近战伤害，不触发剑棒防反；直拳或混合来袭选快步。棒与拳可误中玩家/小孩，哥布林间不互相扣血。
- 哥布林地面绕行，不新增主动跳跃、攀爬或砍倒木；无路等待/重规划，不穿透、传送或移除威胁。小孩已死且没有合法玩家目标时保留现场，不自动寻找新目标或判成功。

### 4.2 救助方式与后续方向

救援期间使用过就计入救助方式，包括未命中。两类均使用即为混用，不要求同一时刻使用。岩炮弹虽然造成物理伤害，仍计入魔法使用。

| 结果类别 | 条件 | 后续结果 |
| --- | --- | --- |
| 剑术救助 | 成功救援，统计期间只使用剑术 | 小孩成为剑术方向教师，小镇兴起相应学习风气 |
| 魔法救助 | 成功救援，统计期间只使用魔法 | 小孩成为魔法方向教师，小镇兴起相应学习风气 |
| 混用救助 | 成功救援，统计期间剑术与魔法均使用过 | 小孩成为魔剑士方向教师，体现剑术与魔法配合 |
| 未获救 | 小孩未获救而遇难 | 该人物剧情结束，不进入其教师后续 |

不提前提示小孩未来会成为重要人物，也不提示救助方式将产生哪些后果。因果关联在回访时由剧情人物揭示。

### 4.3 成败与结束时点

| 情况 | 处理 |
| --- | --- |
| 小孩仍存活，威胁他的魔物被全部消灭 | 救援成功；无需额外护送至安全处 |
| 不救助 | 小孩必然遇难，其剧情结束 |
| 玩家发现遇险后，小孩在救援中死亡 | 判定失败并结束当次尝试，小孩不复活 |
| 小孩在玩家发现遇险前已经死亡 | 允许玩家赶到现场；发现死亡后果后再以失败结束本轮 |
| 玩家发现遇险后转身离开 | 事件继续发展，等小孩遇难后判定失败并结束本轮 |
| 玩家在救援中死亡 | 判定失败，实验结束；本轮单玩家环境下无人执行复活 |

当次尝试不回档挽救死亡后果。用于下一次实验的手动重置见第 8 节；它是实验复测的明确例外。

## 5. 战斗、移动与防御

### 5.1 攻击招式

| 招式 | 已确认效果与命中规则 | 飞行与结束 |
| --- | --- | --- |
| 挥砍 | 剑术；剑刃实际接触角色或树木才算命中；同一次挥砍可分别命中多个对象 | 砍树按第 6 节切面规则处理 |
| 火球 | 魔法；附加火元素的范围攻击；碰到角色、树木或地面时，在接触处产生范围攻击 | 玩家手动瞄准，可见地按球形地图意义的“直线”前进，俯仰须改变高度（具体曲线见下述澄清）；未碰撞时超出最大距离自动燃尽 |
| 岩炮弹 | 魔法招式，物理单体攻击；遇到第一个角色、树木或地面后停止并消失，不穿透 | 玩家手动瞄准，可见地按球形地图意义的“直线”前进，俯仰须改变高度（具体曲线见下述澄清）；未碰撞时到最大距离消失 |

弹道含义先由[球形地图直线澄清](sources/2026-11-06-spherical-projectile-direction.md)提出，[纬度圆纠正](sources/2026-11-06-projectile-latitude-correction.md)明确圆心不一定在球心，[俯仰要求](sources/2026-11-06-projectile-pitch-requirement.md)明确上下瞄准必须改变高度。现已[确认纬度圆及东西向俯仰公式](sources/2026-11-06-latitude-trajectory-confirmation.md)：水平东西向沿等高纬度圆；俯仰时保持当地俯仰角与总速度、径向升降，最大射程按实际飞行路程计。[A06 总体确认](sources/2026-11-06-a06-confirmation-hold-aim.md)进一步确定任意航向保持当地航向/俯仰/总速、同源北轴与零经度，以及局部布局/全部合法发射范围避开极点的准备验证；不静默改变射程或禁止合法瞄准。示例数值不成为游戏参数。

- 三种招式暂不设置体力、魔力消耗或冷却等使用限制；手动瞄准不采用目标锁定或辅助瞄准。
- 仅发射物类魔法（火球、岩炮弹）按住施法键进入瞄准，松开时发射一次；短按也在松开时发射。横斩、竖斩按下直接发动，新挥砍替换未完成挥砍且保留已发生命中。瞄准不计使用招式、不触发攻击指向及首次攻击计时；实际执行成功才按原规则登记。
- 按 [A06 类图确认](sources/2026-11-06-a06-class-confirmation.md)，两种法术分别保持瞄准手势，释放哪个就发射哪个；挥砍与瞄准可并存。取消瞄准不发射，实际防反硬直统一取消未执行输入，已发弹体继续。
- 允许移动、空中及闪避中攻击。发射使用实际发射口和最终相机方向，保留第三视角视差，不自动收敛；发射口被挡不能把弹体生成在墙后。攻击指向独立于命中、射程与视线条件。
- 实验简化为挥砍、火球、岩炮弹命中哥布林或小孩均致死，但第 5.3 节同组防反配对例外优先。火球范围可波及小孩，挥砍与岩炮弹也可误中，玩家须考虑安全救助方式。火球球形范围不增加遮挡衰减，本轮不伤施法者；空气墙吸收弹体而不爆炸，不增加外围模型。
- 玩家与小孩面对哥布林棍棒攻击可承受多次；具体次数留作调参。
- 防反后的摔落伤害不自动套用三种招式命中必死的规则。森林火灾与倒木的角色伤害例外见第 6 节。

### 5.2 移动与闪避

保留走、小跑、奔跑、跳、闪。走、小跑、奔跑是分别需要支持的移动状态。

闪避由玩家发起，动作与避让方向自动选择：哥布林竖挥时用短距离快步，横挥时用翻滚；附近没有来袭攻击，或横竖同时袭来时，都用快步。本轮不设置闪避体力消耗、次数或冷却限制。

只有按下闪避瞬间有无敌帧，其余过程中被攻击碰到仍会受伤。位移与无敌窗口时长留作调参。

按 [A05 总体确认](sources/2026-11-05-a05-confirmation.md)补齐边缘行为：仅接地时开始快步/翻滚；空中不启动、不缓存、不生成无敌窗口。硬直期间不取消硬直、不缓存闪避，恢复后重新按下。接地且未硬直时，已有闪避中新的按下可重新规划并替换旧动作，不等待动画结束；新短窗口从本次被接纳的按下起算，不累加旧窗口时间。长按不重复触发，仍无体力、次数或额外冷却限制。

### 5.3 攻击代格挡／防反

玩家挥砍恰好打中哥布林正在挥动的棒子时，这次挥砍本身就是防反，无需再追加一次攻击才能完成防反：

- 玩家产生硬直，但不受伤。
- 哥布林被击飞，不另外产生硬直；棒子脱手掉落。
- 哥布林落地时承受摔落伤害，不据此直接判定必死或救援完成。
- 若仍存活，按第 4.1 节捡棒或徒手攻击。

按 [A06 总体确认](sources/2026-11-06-a06-confirmation-hold-aim.md)，同一接触组中防反优先于对应棒的伤害，并取消该剑对同一哥布林的直接致死；其他目标独立结算，更早的伤害不能回溯取消。玩家硬直终止后续剑刃和自主水平/闪避位移，期间不接收新的移动、跳跃、闪避或攻击，不缓存离散动作；重力与世界继续，已有短无敌窗口按原时刻到期，已发弹体继续。普通棍棒伤害只扣血，不新增受击硬直。

同一挥动对同一目标至多提交一次有效伤害。无敌拒伤不消耗该次有效伤害额度；窗口结束后须重新检测仍然有效的真实接触才可伤害，不能延迟重放旧命中。弹体首接触结束独立于目标免伤，瞬时爆炸不重复结算。

## 6. 球体世界与森林环境变化

### 6.1 地图边界

世界为球体，必须有可旋转、缩放的球体小地图。玩家活动限于小镇及周边森林，活动边界使用空气墙。实验不对非活动区做建模处理，不要求环球行走后返回小镇。此项按[2026-11-05 用户修订](sources/2026-11-05-a04-air-wall-scope.md)更新，取代此前对外围光滑球面的建模设想；球体小地图仍为必需内容。

本轮“改变地形”通过森林燃烧、树木倒下等环境变化满足，不要求挖坑、隆起等地面形状改变。

### 6.2 火灾与降雨

- 火球范围覆盖到的树木都会起火，降雨及潮湿例外如下。火焰碰到另一棵树即引燃，不要求两棵树本身接触；倒木和草也可燃。
- 救援期间，树木不会因燃烧而倒下，树干只会烧细；砍击倒树规则仍有效。
- 森林火灾只改变环境，不伤害玩家、小孩或哥布林；火球攻击本身仍会造成角色伤害。
- 救援事件开始 3 分钟后降雨，持续 2 分钟。该起点是世界开始运行，不是玩家首次攻击。
- 雨使已有火焰逐渐减弱后熄灭；雨中火球不能引燃树木，但尚未熄灭的火焰仍能继续点燃邻树。
- 雨停后，未烧毁的树仍因雨水保持潮湿，不能立即恢复为可点燃。
- 若救援提前成功，玩家已进入加速阶段，预设降雨仍影响森林变化和回访结果，无需玩家看见降雨过程。

依据 [A09 总体确认](sources/2026-11-06-a09-confirmation.md)，补充以下已确认口径：

- 立木、倒木、草片和树桩统一采用火湿规则；树桩可燃但保留炭化残体，不烧没。火焰按明确空间体积与材料接触传播，覆盖双方运动。
- 雨中新旧火共享当次降雨的衰减进度，逐渐减弱，最迟第 300 秒全部熄灭；传播、砍断和分段不重置雨程。雨后潮湿期禁止火球和火焰新增引燃，完全干燥后恢复可燃。
- 剩余燃料有限，重复接触和材料分裂不补燃料。烧细达到连接/支撑下限后可继续炭化并耗尽燃料，留下无火残体，不自动倒树或移走角色支撑。
- 提前成功与雨后再次点火的晚成功都须结算实际旧雨/旧火；随后生成局部回访环境。新年代无火、干燥，新生植物按布局配置燃料，旧炭化残体不返满；合法新砍树/施法继续生效，旧雨不重播，救助结果不重算。

### 6.3 砍树与倒木

- 砍击产生切面；将切口投影到所在树干横截面，投影面积**超过该横截面积的 80%** 时倒树。
- 各处切口分别判断，不合并不同位置的切口；反复砍同一处会逐次加深、扩大切口。
- 树随砍击方向倒下。倒下树干不砸伤角色，但会阻挡通行。
- 哥布林绕行；玩家可跳过，或用竖劈将倒木分段劈开，沿用切口投影面积超过横截面积 80% 的条件。

依据 [A08 总体确认](sources/2026-11-06-a08-confirmation.md)，补充以下已确认口径：

- 同处以实际进入已有开口认领；不同切口历史独立，重叠投影只计一次。每刀限制真实几何进深，剑的实际姿态同步受阻；不按帧或刀数直接增加百分比。
- 多个独立切口合计贯通、各口却未超过 80% 时，保留最后有效连接并限制继续切入；接受某些交错切口不能继续砍深或靠原切点砍倒，不自动合并面积。
- 烧细后按未扣剑缺口的当前完整外轮廓截面计算比例，仅新增真实砍削触发断开，燃烧本身不倒；烧细仍需保有有效连接。
- 倒向由触发阈值的最后一刀决定，近竖直退化用该刀锁定前向。受控倒木遇角色/障碍停止等待，不推挤、不砸伤；脚下木体暂停运动，会移走支撑的新切削需离开后重新实际砍击。
- 分段保留木段、旧切口与火湿归属，沿原木轴有限分离，受阻保留实际位置，以真实净空判断通路；不保证一刀清通。网格与碰撞提交成功后才允许剑进入新切空间，失败按旧材料阻挡。

### 6.4 回访环境后果

当年火灾与砍树的后果须在回访时可感知：火灾区域有枯木与新芽；砍树只影响小范围，不要求明显的更大后果。砍倒的树干在回访时视为已被人为清理，树桩保留。

## 7. 三十年后的回访

- 成功救援后跨越 30 年，玩家从镇子恢复行动。
- 小孩已成为知名教师，教学方向与当年救助方式对应；公开课与群众讨论提供教师线索。
- 本轮用群众闲聊体现相应学习风气，公开课保留为教师活动背景；不要求完整教学模拟、街头练习模拟或平均能力提升验证。
- 与教师本人相见后触发对当年救援的叙述；玩家错过或离开时会被挽留。此要求不等同锁定移动或强制听完整段对话。
- 魔剑士方向体现剑术与魔法配合，本轮不细化各路线课程和技能清单。
- 成功路线完成条件为：通过群众闲聊感知学习风气，并听到教师本人提起当年救援。玩家学习达标不是完成条件。

依据 [A10 总体确认](sources/2026-11-06-a10-confirmation.md)，补充以下已确认口径：

- 同一世界先完整遮住中间变化，再结算和布置回访；最终环境与人物布置就绪后淡入，三项就绪与实际控制恢复仍按既定握手，不以固定等待时间代替完成。
- 群众接近自动触发，教师近距无遮挡相见触发；一条主要剧情通道，不增加交互键或强制对话模式，不拦移动、转视角及合法施法。
- 离开、地图覆盖、失焦或绑定失效会中断当前片段；返回补播未送达关键片段。挽留要求已经相见且实际离开内圈，限附近一次简短提示，不追赶、不堵路、不远距离自动揭示往事。
- 每类一个完整表达语义的关键片段正常交付才登记完成；提示、开场和取消回调不算，顺序不限。A13 已提前至 A12 前，最终媒体总体及具体类接口均已确认。
- 教师/群众不可受伤，不新增死亡或复活支线；保留玩家通行与弹体真实接触，弹体首接触结束、火球正常爆炸及环境效果继续，挥砍不被其当成硬阻挡。
- 锁定方向不因回访攻击重算，课程只作背景；森林后果通过正常路线呈现并可回访，不增加第三个完成条件，也不以机器送达替代体验验收。

音效与语音按 [A13 总体确认及素材修订](sources/2026-11-06-a13-confirmation-and-audio-sourcing.md)执行：由素材准备任务的 agent 合成中文对白；音效先查找匹配的开放资源，无匹配再合成，产物导入为本地声音资产。运行时采用世界空间音效、单通道清晰 2D 关键语音＋完整字幕，保留自由离开和取消优先；整份媒体作业收尾后才登记关键事实。主动关闭语音允许完整字幕模式，声音异常允许新代次从头字幕降级；记录实际模式，不能把字幕交付当语音验证通过。提供总音量/音效/环境/语音设置，字幕常开，保存冻结与恢复遵守 A11。

## 8. 实验日志与复测

每轮同时记录救助方式与最终分支、成败原因，以及救援、加速发展、回访三个阶段的实际耗时。救援耗时按第 3.2 节计时，未开始攻击时不填成已经发生的救援耗时。

无论成功还是失败，均保留结果日志，由用户手动重启原实验世界，将玩家、小孩、魔物、小镇及实验环境恢复到本轮初始状态，开始下一轮。日志不随世界状态清除；不自动重启，不为每轮新建独立世界，以减少占用。

世界内 NPC 不复活、当次尝试不回档，与实验结束后人工复测重置区分。玩家复活需要其他玩家操作，首轮不具备这一条件。

2026-11-06 [新增技术恢复要求](sources/2026-11-06-a11-checkpoint-recovery.md)、[A11 总体确认](sources/2026-11-06-a11-overall-confirmation.md)及[类图确认](sources/2026-11-06-a11-class-confirmation.md)：采用共同稳定点的完整快照统一保存与恢复，首次提交失败后最多重试 3 次，总共最多 4 次尝试；耗尽后恢复本轮最近有效、完整提交的快照，仍有存储故障则暂停。新恢复代次隔离旧工作，已提交终态不可复活，结果日志从已提交记录重建。主结果记录最终有效分支阶段耗时，废弃分支和恢复停顿另记，跨进程重新锚定时钟，未知耗时明确标记。该机制增加同轮技术故障恢复例外，不作为正常玩法中的主动回档或复活；正常结束后手动开始新轮继续保留。

## 9. 验收标准

### 9.1 因果体验验收

由用户本人亲自体验并比较剑术、魔法、混用和未获救四类结果。总次数与顺序不限定，也不要求亲自覆盖未获救的所有失败原因。

完成回访后，无需游戏外补充解释，须同时满足：

1. 能说清“救助方式 → 教师科目 → 小镇学习风气”的因果链。
2. 感到自己的选择改变了世界。

完成流程、日志正确或能复述剧情，均不能单独替代上述两项体验标准。结果只反映本轮唯一试玩者的反馈。

### 9.2 已确认功能的核对范围

以下仅汇总正文已有要求，不增加功能或额外试玩轮数：

| 核对项 | 应符合的已确认行为 |

### 9.3 输入到渲染反馈性能

输入→核心处理→对应画面反馈的端到端延迟必须**小于50ms**。起点为客户端收到该输入，终点为同一输入的首个对应视觉反馈实际呈现，覆盖排队、核心处理、世界响应、渲染和呈现等待。不能用平均帧率、单帧时间或核心单步耗时替代。

实际受测硬件、画质/显示条件、负载、输入及测量证据按[性能契约](../../performance/001-input-to-render.md)记录。当前只确认目标，未有实测通过结果；工期、投入和受测配置仍未固定。[用户原文](sources/2026-11-06-repository-bootstrap-and-latency.md)。
