## 维护入口

1. 先核对 `main` 和 `state.json`，确认当前线上版本/候选。
2. 线上故障在 `spec/pipelines/maintenance/INCIDENT-<id>.md` 登记：现象、影响、候选基线、受影响文件、验证、回退。
3. 仅对登记文件取得临时热修写权；`tech` 不同时编辑同一文件，共享入口和 UE 二进制资产仍由 tech 写。
4. 修复提交经 `maintenance → ops` 交付；test 直接验证维护候选或其构建产物。
5. 发布走 `ops → main`；失败保持原线上版本，成功后才登记 `x.y.z`。
