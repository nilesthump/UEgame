## 2. 当前有效技术边界与数据流

| 层次 | 已确认技术与职责 | 原因 |
| --- | --- | --- |
| 独立核心 | 标准C++20；Linux Ubuntu24.04/x86_64、GCC13、CMake3.28/CTest；ExperimentSession独占实验运行状态RunState与阶段提交，纯规则函数计算结果 | 同一规则源码可在Linux和Windows验证，避免依赖UE类型；火湿、几何等领域状态仍归UE领域所有者，不承诺已具备完整独立世界模拟 |
| UE世界与适配 | UE5.6.1、Windows MSVC/UBT/UHT；Subsystem唯一拥有Session，各领域负责真实运动/碰撞/导航/几何/环境与装配 | UE承担实际世界模拟和运行适配；核心与表现之间交换明确事实、请求及回执 |
| 输入与表现 | Enhanced Input、相机/UMG/小地图、Niagara/材质、原生声音及字幕 | 接收操作意图和已接受结果，不另建实验状态真源；媒体完成需真实证据 |
| 保存与恢复 | A11协调者、快照参与者、固定字节存储与派生日志 | 捕获同一稳定切点，统一提交重试、故障分流与一致恢复 |
| 开发验证 | 同源核心检查、UE开发测试类、PowerShell本地编排、UAT包、独立人工反馈 | 技术与体验分别验证，所有结论关联实际内容和构建身份 |

运行主链：**操作意图 → UE真实世界行为 → 带轮次/代次/时序的事实 → Session及纯规则 → 强类型效果请求 → UE执行 → 实际回执 → 核心登记阶段或结果**。表现读取已接纳状态，不能从动画、声音结束或未完成任务中补造成功事实。

跨域几何链：A06攻击预算、A08材料/姿态与A09火湿材料采用已确认的共同前缀和整组事务；实际碰撞准备成功才发布，A07导航读取对应真实世界版本。停止、正常结束、跳时、手动新轮与故障恢复沿各自生命周期，不共用一个无条件清空入口。

持久化链：共同稳定切点 → 完整核心/世界/诊断/结果载荷 → 固定提交对象 → 首次加最多三次重试 → 必要时同轮最近有效快照恢复 → 新恢复代次及按阶段实际就绪 → 开放动作。持续故障暂停，不循环回退；已提交终态不可复活，JSONL由已提交结果重建。

验收链：锁定内容与实际工具链 → 同源两平台构建/检查 → 真实UE场景 → 独立包操作和声音核对 → 本人四类比较/原意反馈 → 分项摘要。失败、缺条件或缺反馈同样生成摘要。恢复与字幕降级分别标记，技术检查不能替代因果理解和选择改变世界的感受。
